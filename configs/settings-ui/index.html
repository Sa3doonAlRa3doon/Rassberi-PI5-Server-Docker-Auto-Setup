Set up storage

Start here

  1. Review detected drives and choose data locations.
  2. Choose the apps that start automatically.
  3. Install the package, then enable the permanent settings panel.

Installation runs on the Pi and can take a while. You can follow progress in the operation log. Closing setup stops its temporary web server.

Give every file a place.

Drives are identified by filesystem UUID, so changing USB ports will not change the destination.

Application data placement

Auto select suggests fresh folders. It does not import or move existing files. Databases and app state use SSD storage; bulk files can use a mounted HDD, SSD or microSD.

Changing an existing location pauses affected apps, copies and verifies their files, then recreates only services that were running. No drive is formatted and no source data is deleted.


Choose your Docker apps.
Select which applications to install, then select which installed applications start at boot. Storage groups update to match your install choice.
Dependencies are included automatically. Unselected applications are not prepared, pulled, or started. You can return here later and change the selection without deleting existing data.


Ready for your next drive.
Add the future 2 TB backup HDD when it arrives. Your server can run without it until then.
Portable backups
A separate disk holds ordinary files, database exports, checksums and recovery instructions. You can recover on another Linux machine without this server running. Ext4 needs Linux or an ext4 reader on other operating systems.
Backup creation briefly pauses managed apps for a consistent copy. Unplugged, wrong or full disks stop the backup; source files remain untouched.
Verify a snapshot
Recovery: use portable-backup.py restore-plan and restore to recover into a new staging folder. Full instructions travel with each backup.

Keep a small settings panel.
After installation, enable this private HTTPS panel at port 8788. It lets you change app startup, storage placement and backup settings later.
Temporary setup uses port 8787; the permanent panel uses port 8788. You can also enable the permanent panel in your Pi terminal with sudo python3 /srv/docker/scripts/install-settings-service.py.
